# Stage 21 release note / 阶段 21 发布说明

Stage 21 closes the V1 `RTDETRDet` local execution gap and completes the RT-DETR/RT-DETRv2 contract family in the existing Visual packages. It adds immutable artifact-bound decoded vector-count, raw-query, and v2 profiles; typed single-source auxiliary tensors; bytes/file OpenCV inputs; and decoder semantics for each contract without duplicating `DetectionResult` or coordinate restoration. / 阶段 21 关闭 V1 `RTDETRDet` 本机执行缺口，并在既有 Visual 包内完成 RT-DETR/RT-DETRv2 合同族；新增不可变工件绑定 Profile、typed 单一事实源辅助 tensor、bytes/file OpenCV 输入与各合同解码语义，不复制结果或坐标恢复。

The original SHA `6769a122...` scalar-count ONNX remains a reproducible `p2o.Tile.3` failure. Separate decoded vector-count ONNX/IR and raw-query ONNX artifacts pass real ORT/OpenVINO CPU execution. A same-image gate compares category, score, box, order, threshold decision, source coordinates, and canonical fields; timings are recorded only as one-run diagnostics. RT-DETRv2 official opset-16 export semantics are implemented and tested, but real execution skips until `DEPLOYSHARP_RTDETRV2_ONNX` points to an exact external artifact. / 原 scalar-count ONNX 保留失败证据；独立 vector-count ONNX/IR 与 raw-query ONNX 通过真实双后端执行及同图字段对齐。RT-DETRv2 官方 opset-16 合同已实现和测试，但在配置精确外部工件前真实执行 skip。

Three new structured manifests bring the portable-detector set to eight. All remain `External`, `redistributionAllowed:false`, outside the empty official catalog, and not `AlgorithmVerified`. The package-only `visual-rtdetr` consumer installs Core, Visual, Visual.OpenCV, one backend and application-selected native runtimes; it skips stably without external files and prints `DEPLOYSHARP_VISUAL_RTDETR_CONSUMER_OK` only after a real result. / 新增三份结构化清单后总数为八，全部保持 External、禁止再分发、不进入空官方目录且不标 AlgorithmVerified。仅包 consumer 缺外部文件时稳定 skip，真实成功后才输出成功标记。

No model, image, checkpoint, Python environment, native runtime, TensorRT dependency, official catalog entry, Release, tag, asset upload, Actions dispatch, commit, or push is added. / 未加入模型、图片、checkpoint、Python 环境、native runtime、TensorRT、官方目录条目、Release、tag、上传、Actions、commit 或 push。
