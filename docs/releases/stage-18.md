# Stage 18 release note / 阶段 18 发布说明

Stage 18 adds the DEIMv2, RF-DETR detection, RF-DETR segmentation, RT-DETR, and PP-YOLOE deployment contracts to the existing Visual packages. Profiles bind exact named ONNX tensors, output semantics, image geometry, source metadata and optional artifact SHA256; decoders reuse the existing detection and instance-segmentation results. / 阶段 18 在既有 Visual 包中增加 DEIMv2、RF-DETR 检测、RF-DETR 分割、RT-DETR 与 PP-YOLOE 的部署合同。Profile 绑定精确具名 ONNX tensor、输出语义、图像几何、来源元数据和可选工件 SHA256；Decoder 复用既有检测和实例分割结果。

`Visual.OpenCV` now exposes artifact-driven portable preprocessing. DEIMv2 uses black, floor-rounded centered letterbox and full-canvas target sizes; RF-DETR uses direct RGB ImageNet-normalized resize; inspected PaddleDetection exports use direct RGB `/255` resize with explicit geometry tensors. / `Visual.OpenCV` 现提供由工件驱动的便携前处理。DEIMv2 使用黑色、向下取整的居中 letterbox 和完整画布 target size；RF-DETR 使用直接 RGB ImageNet 归一化 resize；已检查的 PaddleDetection 导出使用直接 RGB `/255` resize 和显式几何 tensor。

The authorized local matrix passed all five ORT integration tests, with RT-DETR passing by asserting its known `p2o.Tile.3` contract failure. OpenCV-to-ORT passed four runnable paths, and OpenCV-to-OpenVINO passed RF-DETR detection and segmentation. This is local backend evidence only. DEIMv2/RT-DETR OpenVINO port aliases, PP-YOLOE OpenVINO dynamic-rank Squeeze, exact artifact provenance, redistribution rights, official goldens and field-level cross-backend comparisons remain blockers. / 获授权本地矩阵通过全部五个 ORT 集成测试，其中 RT-DETR 通过断言其已知 `p2o.Tile.3` 合同失败。OpenCV 到 ORT 通过四个可执行路径，OpenCV 到 OpenVINO 通过 RF-DETR 检测与分割。这仅是本地后端证据。DEIMv2/RT-DETR OpenVINO 端口别名、PP-YOLOE OpenVINO 动态 rank Squeeze、精确工件来源、再分发权利、官方 golden 和字段级跨后端对比仍是阻断项。

All five ModelPack candidates remain `External` and the embedded official ModelFactory catalog remains empty. No model, image, native runtime, TensorRT dependency, GitHub Release, tag, asset upload or workflow dispatch was created. The package continues to use the repository English README and `nuget/logo.jpg`. / 五个 ModelPack 候选均保持 `External`，内置官方 ModelFactory catalog 继续为空。本阶段没有创建模型、图片、native runtime、TensorRT 依赖、GitHub Release、tag、asset 上传或 workflow dispatch。包继续使用仓库英文 README 和 `nuget/logo.jpg`。
