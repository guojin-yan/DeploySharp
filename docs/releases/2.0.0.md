# DeploySharp 2.0.0 版本说明

本文描述 2.0.0 的功能与使用边界。是否已发布请以 [NuGet](https://www.nuget.org/packages/JYPPX.DeploySharp.Core) 和 [GitHub Releases](https://github.com/guojin-yan/DeploySharp/releases) 为准。

## 本版本提供什么

DeploySharp V2 为 .NET 应用提供显式的模型、张量、推理会话与后端接口。它是一次全新的 API 设计，不提供与 V1 的源码、二进制或配置兼容。14 个包按应用实际需要组合安装，原生运行时由应用选择和部署；详见[包组合指南](../articles/package-combinations.md)。

| 模块 | 主要能力 |
| --- | --- |
| 通用推理 | 类型明确的输入输出、取消与资源管理、Batch 调度、多个独立 Session 的池化和并发调用 |
| 视觉任务 | 分类、目标检测、语义与实例分割、关键点、旋转框、异常检测、背景移除，以及自定义前后处理和结果类型 |
| 图像工作流 | 可配置 Resize/Letterbox/CenterCrop、颜色与归一化；异步流水线、滑动窗口、ROI 配置、坐标回映射与结果合并 |
| PaddleOCR | PP-OCRv4/v5/v6 的 DET/REC/CLS 组合，检测裁剪与识别流水线、动态 Batch 和多 Session 调度 |
| 文档解析 | PP-Structure 版面、表格、公式、印章、UVDoc、Chart2Table 的任务接口与组合流程；精确支持范围见模型指南 |
| 模型管理 | ModelPack 清单、可选 Preview 目录、按需下载、大小/SHA-256 校验和离线缓存 |
| 其它任务 | SAM v1、CLIP、BLIP Caption Base 和 Qwen2.5 GGUF 的已验证工件；更大的模型族保留明确的实验性或未验证状态 |

完整模型名称见[模型支持指南](../articles/model-support.md)，逐工件和逐后端状态见[验证矩阵](../model-backend-verification-matrix.md)。性能数据按[设备与测量协议](../articles/device-performance-benchmarks.md)读取，不能从单个最快值推断所有模型。

## 从预览版升级

将应用使用的全部 DeploySharp 包升级到同一版本，检查后端原生库与目标框架，再复核自定义 Profile、前后处理、Batch 和资源所有权。预览版之后增加的接口仅存在于当前源码和包含这些改动的新包中。运行示例见[使用教程](../articles/usage-tutorial.md)，已有 V1 应用见[迁移指南](../articles/v1-model-migration.md)。

PP-OCRv5 的 ModelFactory 主目录使用 `models-visual.1` 的完整 ModelPack。完整 OCR/PP-Structure 集合通过 `PaddleOcrReleaseClient` 从 `models-paddleocr` 按模型获取；两个目录的部分 Server 模型字节不同，必须配对使用各自的清单。

## 平台与已知边界

- 本版本优先验证 Windows 10/11 x64，ONNX Runtime、OpenVINO、OpenCV DNN 和 TensorRT 的通过范围以精确模型矩阵为准。
- TensorRT Engine 绑定目标设备、运行时和动态 Shape Profile；应用应在目标环境转换或加载匹配 Engine。
- OpenCV DNN 受导入器和算子支持限制；`✗` 或 `—` 不因模型可下载而变成通过。
- SAM2/SAM3 视频、Whisper 完整 Bundle、Donut 多页、BLIP VQA/BLIP-2/InstructBLIP、Qwen2.5-VL、Phi Vision、SigLIP 2 及部分 LayoutLMv3/Pix2Struct 任务头不作为完整多后端能力承诺。
- 不同目标框架的能力有所差异；ROI、滑动窗口及 tokenizer 的具体要求见[平台与目标框架](../articles/platform-support.md)。

发现问题时，请提供包版本、操作系统、后端与原生运行时版本、精确模型标识、输入规格和最小复现代码。
