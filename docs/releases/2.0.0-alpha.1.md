# DeploySharp 2.0.0-alpha.1

## Stage 27: Document intelligence and layout understanding / 阶段 27：文档智能与版面理解

Stage 27 adds one artifact-bound LayoutLMv3/Donut/Pix2Struct contract, explicit caller-OCR versus OCR-free ownership, typed page/layout/patch/token/schema/KV state, managed Donut tokenization and strict structured parsing, official Donut ORT/OpenVINO/OpenCV fidelity, ModelFactory page/schema/OCR/Processor identity, three External manifests, a package-only consumer, and a 63-entry Stages 1-27 inventory. LayoutLMv3 and Pix2Struct remain precise blockers. No model upload, catalog entry, Release asset, Actions run, or TensorRT implementation was added. / 阶段 27 新增统一文档模型合同、OCR/页/版面/Patch/Token/Schema/KV 所有权、Managed Donut Tokenizer、严格解析、双后端/OpenCV 官方保真、ModelFactory 文档 Identity、三份 External Manifest、纯包 Consumer 和 63 条全阶段清单；LayoutLMv3/Pix2Struct 保持 blocker，未执行上传、Catalog、Release、Actions 或 TensorRT。

## Stage 26: Native multimodal dialogue / 阶段 26：原生多模态对话

Stage 26 adds an artifact-bound LLaVA OneVision Vision/projector + managed Qwen2 tokenizer/embedding + Prefill/KV Decode pipeline, anyres OpenCV input, ModelFactory image/context query identity, three External manifests, package-only consumer, acquisition guide, and a regenerated 60-entry Stages 1-26 inventory. Official/current-runtime drift is retained; Qwen2.5-VL and Phi-3.5 Vision remain blockers. No model upload, catalog entry, Release asset, Actions run, or TensorRT implementation was added. / 阶段 26 新增 LLaVA OneVision 三图/KV 流水线、Anyres OpenCV、ModelFactory 图像/Context Identity、三份 External Manifest、仅包 Consumer、获取指南和 60 条全阶段清单；Runtime 差异如实保留，Qwen/Phi 保持 blocker，未执行上传、Catalog、Release、Actions 或 TensorRT。

## Stage 25: BLIP-family generation / 阶段 25：BLIP 模型族生成

Stage 25 adds artifact-bound BLIP-family generation, a stateful two-session caption lifecycle, exact WordPiece and generation identity, Pillow-compatible OpenCV preprocessing, official BLIP Caption ORT/OpenVINO fidelity, explicit BLIP VQA/BLIP-2/InstructBLIP blockers, four External manifests, and an all-stage model inventory/acquisition guide set. No model binary, vocabulary, image, native runtime, catalog entry, Release asset, Actions run, or TensorRT implementation was added. / 阶段 25 新增工件绑定 BLIP 生成、双 Session 生命周期、精确 Tokenizer/生成 Identity、Pillow-compatible OpenCV、官方 Caption 双后端保真、其余路径 blocker、四份 External Manifest 及全阶段模型清单/获取指南。未加入模型资产、目录、Release、Actions 或 TensorRT。

## Stage 24: Vision-language dual encoders / 阶段 24：视觉语言双编码器

Stage 24 adds artifact-bound CLIP/SigLIP image and text encoders, tokenizer and projection identity, owned embedding caches, exact CLIP softmax versus SigLIP sigmoid semantics, zero-shot classification, and bidirectional cross-modal retrieval. The audited split graphs run on ORT/OpenVINO CPU against official retained feature goldens. SigLIP 2 and Pillow-exact OpenCV preprocessing remain explicit External blockers. No model, tokenizer, image, native runtime, catalog entry, Release asset, Actions run, or TensorRT implementation was added. / 阶段 24 新增工件绑定的 CLIP/SigLIP 图文编码器、Tokenizer/Projection Identity、自有 Embedding 缓存、精确 CLIP Softmax 与 SigLIP Sigmoid 语义、零样本分类和双向跨模态检索。已审计双子图在 ORT/OpenVINO CPU 对齐保留的官方 Feature Golden；SigLIP 2 与 Pillow 精确 OpenCV 前处理保持 External 阻断。未加入模型、Tokenizer、图片、Native Runtime、目录条目、Release 资产、Actions 执行或 TensorRT 实现。

## Stage 22: Segment Anything family / 阶段 22：Segment Anything 模型族

## Stage 21: RT-DETR family closure / 阶段 21：RT-DETR 模型族收口
