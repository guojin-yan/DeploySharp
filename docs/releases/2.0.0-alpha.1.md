# DeploySharp 2.0.0-alpha.1

- Date / 日期: 2026-08-06
- Status / 状态: Alpha development / Alpha 开发中
- Compatibility / 兼容性: Clean V2 API; no V1 source, binary, configuration or behavior compatibility. / 全新 V2 API；不提供 V1 源码、二进制、配置或行为兼容。

## Current increment: Visual anomaly detection / 当前增量：Visual 异常检测

### Added / 新增

- Backend-neutral image-level anomaly score and pixel-level anomaly map contracts, owned maps/masks/results, canonical result SHA256, stable diagnostics and typed `AnomalyPipeline`. / 新增后端无关的图像级异常分数与像素级异常图合同、自有 map/mask/result、规范结果 SHA256、稳定诊断及类型化 `AnomalyPipeline`。
- Explicit map names, layout, channel count, value semantics, aggregation, normalization, fixed threshold, nearest/bilinear-half-pixel interpolation and source restoration. / 新增显式异常图名称、layout、通道数、数值语义、聚合、归一化、固定阈值、nearest/bilinear-half-pixel 插值与源图恢复。
- Deterministic ONNX, OpenVINO IR and PNG fixtures with size/SHA256 manifests; real ONNX Runtime CPU, OpenVINO CPU ONNX/IR and Visual.OpenCV integration evidence. / 新增确定性 ONNX、OpenVINO IR 与 PNG 夹具及大小/SHA256 清单；提供真实 ONNX Runtime CPU、OpenVINO CPU ONNX/IR 与 Visual.OpenCV 集成证据。
- ModelPack multi-file integrity tests, ModelFactory offline Preview selection and package-only Visual anomaly clean consumer. / 新增 ModelPack 多文件完整性测试、ModelFactory 离线 Preview 选择和纯包 Visual anomaly clean consumer。
- Bilingual guide, AlgorithmVerified admission template, ADR and API reference documentation. / 新增双语指南、AlgorithmVerified 准入模板、ADR 与 API 参考文档。
- The warmed 12-iteration contract-fixture entry recorded preprocess P50/P95 `0.622/0.998 ms`, backend execute `0.129/0.251 ms`, postprocess `0.016/0.020 ms`, end-to-end `0.780/1.306 ms`, and `224256` current-thread managed bytes. These values are local regression evidence, not a production benchmark. / 预热后的 12 次合同夹具入口记录前处理 P50/P95 `0.622/0.998 ms`、后端执行 `0.129/0.251 ms`、后处理 `0.016/0.020 ms`、端到端 `0.780/1.306 ms` 及当前线程托管分配 `224256` 字节；这些数值只用于本机回归，不是生产性能基准。

### Dependencies and package boundary / 依赖与包边界

- `JYPPX.DeploySharp.Core` remains independent of OpenCV, inference runtimes and Visual. / `JYPPX.DeploySharp.Core` 继续不依赖 OpenCV、推理运行时或 Visual。
- `JYPPX.DeploySharp.Visual` depends only on Core; image input remains in optional `JYPPX.DeploySharp.Visual.OpenCV`. / `JYPPX.DeploySharp.Visual` 仅依赖 Core；图像输入继续位于可选的 `JYPPX.DeploySharp.Visual.OpenCV`。
- Current verified packages are ONNX Runtime 1.28.0, OpenVINO managed 3.3.0 with Windows runtime 2026.2.1, and OpenCV API/runtime 5.0.0-preview.1 on Windows x64. / 当前验证包为 ONNX Runtime 1.28.0、OpenVINO managed 3.3.0 + Windows runtime 2026.2.1，以及 Windows x64 上的 OpenCV API/runtime 5.0.0-preview.1。
- NuGet packages include `nuget/logo.jpg` and the repository English `README.md`; native runtime selection remains application-owned. / NuGet 包包含 `nuget/logo.jpg` 与仓库英文 `README.md`；native runtime 仍由应用显式选择。

### Known limitations / 已知限制

- Repository anomaly fixtures are adapter-contract graphs, not official algorithm models or accuracy/performance claims. / 仓库异常夹具是适配合同图，不是官方算法模型，也不构成精度/性能结论。
- Percentile and model-provided threshold policies are explicitly unsupported in this alpha. / 本 alpha 显式不支持百分位与模型提供阈值策略。
- TensorRT remains excluded while `JYPPX.TensorRT.CSharp.API` is under development. / `JYPPX.TensorRT.CSharp.API` 开发期间继续排除 TensorRT。
- The embedded official ModelFactory catalog remains empty; no model Release/tag/asset is published. / 内置 ModelFactory 官方目录保持为空；未发布模型 Release/tag/asset。

## V2 alpha baseline / V2 alpha 基线

The same package version currently contains Core contracts, LLM + LLamaSharp, ModelPack.Json, ModelFactory, Visual classification/detection/semantic segmentation/Pose/instance segmentation/OBB/OCR/anomaly modules, ONNX Runtime and OpenVINO backends, and the optional OpenCV image adapter. Detailed public API changes remain in [API changes alpha.1](../articles/api-changes-alpha1.md). / 当前同一包版本还包含 Core 契约、LLM + LLamaSharp、ModelPack.Json、ModelFactory、Visual 分类/检测/语义分割/Pose/实例分割/OBB/OCR/异常模块、ONNX Runtime 与 OpenVINO 后端，以及可选 OpenCV 图像适配器。详细公共 API 变更继续记录在 [API changes alpha.1](../articles/api-changes-alpha1.md)。
