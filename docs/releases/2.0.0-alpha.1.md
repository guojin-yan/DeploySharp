# DeploySharp 2.0.0-alpha.1 发布说明

发布日期：`2026-09-03`
状态：Windows x64 工程预览版

`2.0.0-alpha.1` 是 DeploySharp V2 的首个公开预览版本。V2 采用全新的 API 和包边界，不提供与 V1 的源码、二进制、配置或行为兼容。

## 本版本包含的能力

- `Core`：模型、张量、会话、诊断、取消和资源释放等后端无关契约。
- `Visual`：分类、检测、语义分割、实例分割、姿态、旋转框、OCR、异常检测、背景移除、提示分割和视觉语言工作流。
- 后端：ONNX Runtime、OpenVINO、OpenCV DNN、TensorRT 与 LLamaSharp 适配边界。原生运行时由应用自行安装和部署。
- `ModelPack` 与 `ModelFactory`：模型清单、文件完整性校验、Release 制品下载和离线缓存复用。
- 示例：按核心、视觉、后端、多模态、LLM、模型和性能基准分组的完整案例。

## 当前可验证范围

| 项目 | 当前状态 |
| --- | --- |
| 操作系统 | Windows 10/11 x64 已有构建、测试和推理证据 |
| CPU 后端 | ONNX Runtime、OpenVINO、OpenCV DNN 已在具名模型上验证 |
| GPU 后端 | TensorRT 11 + CUDA 12.9 已在具名 Windows 测试机的视觉和 PaddleOCR 流水线上验证 |
| 模型目录 | 42 个 Preview 条目、43 个制品变体；每个目录模型有独立案例 |
| 文档与 API | DocFX 用户文档、性能复现方法和 API 参考可用 |

精确到模型制品和后端的状态以[模型与后端验证矩阵](../model-backend-verification-matrix.md)为准；可复现的实测时间以[设备性能实测](../articles/device-performance-benchmarks.md)为准。

## 快速开始

```powershell
dotnet restore DeploySharp.sln --locked-mode
dotnet build DeploySharp.sln -c Release --no-restore
dotnet run --project samples/01-core -c Release
```

安装应用依赖、注册后端、创建会话和执行视觉模型的完整示例见[使用教程](../articles/usage-tutorial.md)。模型下载与哈希校验见[ModelFactory 指南](../articles/modelfactory-getting-started.md)。

## 已知限制

- 当前正式验证范围仅覆盖 Windows x64；Linux、macOS、Windows ARM64、移动平台和 NPU 尚未形成发布级推理证据。
- 目录中的 `Preview` 表示制品可选择和完整性可校验，不等于所有后端都支持该模型。
- SAM2/SAM3 视频、Whisper 完整发布 Bundle、Donut 多页和 TensorRT、BLIP VQA/BLIP-2/InstructBLIP、Qwen2.5-VL、Phi Vision、SigLIP 2 及部分 LayoutLMv3/Pix2Struct 任务头尚未形成完整多后端运行证据。
- TensorRT 依赖用户安装兼容的 NVIDIA 驱动、CUDA、cuDNN 和 TensorRT；引擎制品与设备、版本和动态 shape profile 相关。
- 公共 API 和包版本仍可能在后续预览版本中调整。
