# Stage 19 release note / 阶段 19 发布说明

Stage 19 adds complete artifact-bound execution slices for PaddleOCR detection and recognition, Anomalib PaDiM/PatchCore exports, and BRIA RMBG 1.4/2.0 alpha outputs in the existing Visual packages. The implementation reuses existing OCR, anomaly, geometry, image-transform, pipeline, and managed tensor infrastructure. / 阶段 19 在现有 Visual 包中加入完整的 PaddleOCR 检测/识别、Anomalib PaDiM/PatchCore 导出与 BRIA RMBG 1.4/2.0 alpha 工件绑定执行切片。实现复用既有 OCR、异常、几何、图像变换、pipeline 与托管 tensor 基础设施。

`Visual.OpenCV` now exposes official-style PP-OCRv5 BGR resize/normalization, recognition crop normalization, Anomalib RGB scaling, and artifact-bound BRIA RGB preparation. `OcrCharacterSet` supports multi-scalar dictionary tokens, and `AlphaMask` supports deterministic SHA256 and RGB composition. / `Visual.OpenCV` 现提供官方风格 PP-OCRv5 BGR resize/归一化、识别 crop 归一化、Anomalib RGB 缩放与工件绑定 BRIA RGB 前处理。`OcrCharacterSet` 支持多标量字典 token，`AlphaMask` 支持确定性 SHA256 与 RGB 合成。

The authorized local matrix passed all six gated ORT tests and all three representative OpenVINO tests. The real same-image parity test passed OCR field comparison, exact anomaly binary mask comparison, anomaly-map max error `5.9604645e-7`, and alpha max error `8.46386e-6`. The package-only consumer restored from local packages, ran eight OCR regions plus anomaly and alpha, and printed `DEPLOYSHARP_VISUAL_OCR_ANOMALY_CONSUMER_OK`. / 获授权本地矩阵通过全部六个门控 ORT 测试和三个代表性 OpenVINO 测试。真实同图对齐测试通过 OCR 字段比较、异常二值 mask 精确比较，异常图最大误差为 `5.9604645e-7`，alpha 最大误差为 `8.46386e-6`。仅包消费者从本地包恢复，运行八个 OCR 区域及异常/alpha，并打印成功标记。

Eight ModelPack candidates and four ModelFactory Preview admission records remain External with `redistributionAllowed:false`; the embedded official catalog remains empty. RMBG 2.0 metadata-dynamic artifacts pass at 1024 but reproduce an internal reshape failure at 256. Exact checkpoint/export provenance, licenses, official algorithm goldens, and redistribution approval remain blockers. No model, dictionary, image, native runtime, TensorRT dependency, GitHub Release, tag, asset upload, or workflow dispatch was created. / 八份 ModelPack 候选与四条 ModelFactory Preview 准入记录保持 External 与 `redistributionAllowed:false`；内置官方 catalog 继续为空。RMBG 2.0 元数据动态工件在 1024 通过，但在 256 可复现内部 reshape 失败。精确 checkpoint/导出来源、许可证、官方算法 golden 与再分发授权仍是 blocker。本阶段未创建模型、字典、图片、native runtime、TensorRT 依赖、GitHub Release、tag、asset 上传或 workflow dispatch。
