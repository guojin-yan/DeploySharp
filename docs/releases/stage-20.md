# Stage 20 release note / 阶段 20 发布说明

Stage 20 closes the V1 `PaddleOcrCls` execution row and extends PaddleOCR into a detector-classifier-recognizer artifact family. The existing Visual OCR results, orientation decoder/pipeline/workflow, OpenCV crop/rotation path, named Core tensors, and backend adapters are reused. / 阶段 20 关闭 V1 `PaddleOcrCls` 执行行，并把 PaddleOCR 扩展为检测-分类-识别工件族；复用现有 Visual OCR 结果、方向 Decoder/pipeline/workflow、OpenCV crop/rotation、Core named tensor 与后端适配器。

Added APIs declare explicit orientation strategies and rejection policy, support validated two-class `0/180` schemas beside the existing four-class schema, bind legacy BGR and PP-LCNet RGB classifier profiles, add accumulated orientation timing, and expose a three-model `OcrPipeline` constructor with per-region provenance. / 新 API 显式声明方向策略与拒绝策略，在既有四类 Schema 旁支持已验证的二类 `0/180`，绑定 legacy BGR 与 PP-LCNet RGB Profile，增加分类累计 timing，并提供保留逐区域来源的三模型构造函数。

The authorized local matrix passed all three local classifiers on ORT CPU, both distinct contracts on OpenVINO CPU, and a real same-image three-model comparison across eight detected regions. Prepared-tensor SHA values are pinned for both preprocessing contracts. Timing is retained only as single-run diagnostics. Three structured ModelPack candidates and one ModelFactory support row remain External with `redistributionAllowed:false`; the official catalog remains empty. / 授权本地矩阵通过三个本地分类器的 ORT CPU、两种不同合同的 OpenVINO CPU 以及八区域真实同图三模型比较；两种前处理固定 prepared-tensor SHA。时间仅作为单次诊断。三份 ModelPack 候选和一条 ModelFactory 支持行保持 External 与禁止再分发，官方 catalog 继续为空。

The package-only consumer installs Core, Visual, Visual.OpenCV, one backend, and explicit native runtimes, skips stably without external files, and prints `DEPLOYSHARP_VISUAL_PADDLE_OCR3_CONSUMER_OK` after a complete run. No model, image, dictionary, Python file, native runtime, TensorRT dependency, release, tag, upload, or workflow dispatch is added. / 仅包消费者安装 Core、Visual、Visual.OpenCV、单一后端和显式 native runtime；缺少外部文件时稳定 skip，完整执行后打印成功标记。本阶段不加入模型、图片、字典、Python、native runtime、TensorRT、release、tag、上传或 workflow dispatch。
