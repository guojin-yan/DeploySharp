# Stage 35: all-package release-candidate governance / 阶段 35：全包发布候选治理

Stage 35 adds an executable release-candidate gate for all nine packable projects. It validates central versions, package/project metadata, 82 TFM groups, lock/assets graphs, nuspec dependencies, strict payloads, XML documentation, assembly references, internal dependency closure, symbol policy, and release blockers. Five disposable mutations prove rejection of native leakage, wrong TFM, version drift, missing repository metadata, and unexpected payload. No dependency, public API, ModelFactory behavior, Manifest, or model asset changed. / 阶段 35 新增覆盖九个可打包项目和 82 个 TFM 组的发布候选门，并以五类临时突变证明拒绝能力；没有升级依赖或修改公共 API、ModelFactory、Manifest 与模型资产。

Two independent full packs were semantically identical for all nine packages while raw archives were `0/9` identical because of NuGet-generated container metadata. All packages contain the expected license/README/icon/repository metadata and managed DLL/XML payload only. Backend.LlamaSharp still depends only on managed `LLamaSharp 0.27.0`; native runtimes remain consumer-owned. The current symbol policy is `not-produced`, all nine development packages are unsigned, and verification returns expected `NU3004`; release eligibility remains blocked by a dirty worktree and unsigned packages. / 两次全包打包语义 `9/9` 一致、原始 ZIP `0/9` 一致；包元数据和托管 payload 通过，native 所有权不变。当前不产出符号包且九包未签名，因此尚不具备发布资格。

The 30-project package-only matrix passed 16 fixture/basic paths, skipped 11 exact external-file gates, and retained three explicit external blockers with no unexpected failure. Separate no-native and caller-owned CPU Llama graphs passed `DS-NATIVE-6001` and real exact-SHA execution. Focused tests passed `379/49/0`, the environment-neutral solution passed `378/50/0`, and vulnerability/deprecated audits found zero findings across both the solution and all 30 consumers. Outdated third-party packages were reported without upgrades; the NuGet CLI local-prerelease aggregation limitation is retained in the detailed audit. / 30 项纯包矩阵、Llama 无 native/真实 CPU、focused 与全解决方案回归均通过预期分类；solution 与全部 consumer 的漏洞/弃用审计为零，outdated 只报告未升级，并保留 NuGet CLI 本地 prerelease 聚合限制。

The exact Qwen model, five source sidecars, and retained Stage 31 evidence remained immutable; admission returned `ADMITTED missing=none`, inventory stayed `69/56`, all publication fields stayed false, and the official catalog stayed empty. No model, Tokenizer, sidecar, evidence, package, tag, Release, upload, or Actions workflow was published. / 模型和旧证据无漂移，准入与清单状态不变；本阶段没有发布或上传操作。
