# Stage 27 API changes / 阶段 27 API 变更

- Added immutable `DocumentUnderstandingProfile`, `DocumentUnderstandingBundle`, `DocumentArtifactContract`/binding, processor/tokenizer/schema/KV contracts, exact Donut ONNX/OpenVINO factories, and explicit LayoutLMv3/Pix2Struct blocker factories. / 新增统一不可变文档 Profile/Bundle、工件与 Processor/Tokenizer/Schema/KV 合同、Donut 双格式工厂及两个官方 blocker。
- Added typed `DocumentWord`, normalized boxes, token-word alignment, `PreparedDocumentPage`, ordered `PreparedDocument`, task requests, generation token sequences, encoded state, KV summary, timing, result, structured node, parse status, and field/source-page provenance. / 新增 Words/Boxes/Alignment、页/文档、任务、状态、KV、Timing 与结构结果 DTO。
- Added `DocumentUnderstandingSession` set/encode document, repeated task generation, Prefill, named self/cross past-present Decode, streaming callback, async cancellation/timeout, deterministic single-writer rejection, clear, and exactly-once child-session disposal. / 新增三 Session 生命周期、Prefill/KV Decode、流式、取消/超时、并发拒绝、Clear 与释放。
- Added `DonutDocumentTokenizer` on net8/net9/net10 with verified SentencePiece/tokenizer/added-token identity, XLM-R fairseq ID mapping, exact prompt/special tokens, EOS cleanup, and an explicit older-TFM capability boundary. / 新增 Managed Donut Tokenizer、官方资产校验、XLM-R ID 映射与旧 TFM 边界。
- Added bounded `DocumentStructuredOutputParser` for balanced Donut tags. It preserves raw token/text/schema/provenance and never repairs invalid structure into success. / 新增容量受限且不静默修复的 Donut 结构解析器。
- Added `OpenCvDocumentUnderstandingInputFactory` for PNG/JPEG/bytes, BGR/RGB/gray/alpha, one decode, source/page identity, official Donut resize/thumbnail/center-pad/normalize, and typed LayoutLMv3/Pix2Struct capability boundaries. / 新增单次 Decode 的文档 OpenCV 工厂与官方 Donut 预处理。
- Added stable `DS-VISUAL-5002..5010` for invalid contract, limit, state, identity, concurrency, tokenizer, generation, schema, and unavailable capability. Existing cancellation, timeout, inference, native-load, and disposed codes remain unchanged. / 新增稳定文档错误码，既有错误映射不变。
- Extended ModelFactory artifact JSON and `ModelQuery`/`ModelBundleQuery` with positive `pageCount` plus exact `schemaId`, `ocrOwnership`, and `processorId`. Bundle selection rejects missing or mixed page/context/Processor/Tokenizer/OCR/Schema/KV identity and still requires reproducible conversion metadata. / ModelFactory 新增页数、Schema、OCR 与 Processor 查询及混配拒绝。

No existing public type was removed. There is no V1 shim, model-specific NuGet, bundled model/tokenizer/processor/schema/golden/native runtime, Python runtime fallback, remote OCR/API, official-catalog admission, model upload/download URL, Release/Actions write, or TensorRT implementation. / 未删除既有 API；无 Shim、单模型包、内置资产、Python/远程回退、Catalog/上传/Release/Actions/TensorRT。
