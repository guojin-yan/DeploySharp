# Supported model roadmap / 支持模型路线表

## Current admission snapshot / 当前准入快照

The embedded ModelFactory catalog contains **42 entries**, all with `preview` status. They cover one Qwen GGUF, PaDiM, BRIA RMBG 1.4/2.0, published vision/detector bundles, and six PP-OCRv5 mobile/server bundles. Public availability does not promote an entry to `AlgorithmVerified`, and the project is not GA. The V1 strict completion count remains `0/32`; local backend coverage remains `32/32`. / 内置 ModelFactory catalog 当前有 **42 条记录**，状态全部为 `preview`，覆盖一个 Qwen GGUF、PaDiM、BRIA RMBG 1.4/2.0、已发布视觉/检测器 bundle，以及六个 PP-OCRv5 mobile/server bundle。公开可下载不等于 `AlgorithmVerified`，项目也尚未 GA。V1 严格完成数仍为 `0/32`，本机后端覆盖仍为 `32/32`。

| Status / 状态 | Meaning / 含义 |
| --- | --- |
| `ContractVerified` | The task/profile contract and deterministic decoding behavior are tested. / 任务或 Profile 合同及确定性解码行为已测试。 |
| `LocalBackendVerified` | The exact local artifact ran on the named local backend/device matrix. / 精确本机工件已在声明的本机后端/设备矩阵运行。 |
| `Preview` | A reviewed ModelPack is published with immutable Release identity, size, SHA-256, and source/license metadata; preview quality may still lack full algorithm or platform evidence. / 已审核 ModelPack 具备不可变 Release、大小、SHA-256 与来源/许可元数据，但仍可能缺完整算法或平台证据。 |
| `AlgorithmVerified` | Exact upstream preprocessing/export/postprocessing parity, official goldens, performance evidence, and admission review are complete. / 精确上游前处理、导出、后处理一致性、官方 golden、性能证据和准入审核均完成。 |
| `GA` | All package, platform, native-runtime, security, documentation, installation, and release gates pass. / 包、平台、原生运行时、安全、文档、全新安装和发布门禁全部通过。 |

## First PP-OCRv5 admission review / 首个 PP-OCRv5 准入审核

The first candidate selected for an `AlgorithmVerified` review is `paddleocr/ppocrv5/mobile-cls`. It has a single orientation-classification graph, fixed `0_degree,180_degree` label order, byte-identical exporter reproduction, immutable Preview Release binding, ORT/OpenVINO parity on a fixed official image, and an independent CPU result from the pinned Paddle Predictor. The candidate remains `Preview` because `license-and-redistribution` is open: no attributable approval covers redistribution of the model archive and derived ONNX. See [ADR 0037](../adr/0037-ppocrv5-first-algorithm-admission.md). / 首个 `AlgorithmVerified` 审核候选为 `paddleocr/ppocrv5/mobile-cls`。它具有单一方向分类图、固定的 `0_degree,180_degree` 标签顺序、字节级导出复现、不可变 Preview Release 绑定、固定官方图像上的 ORT/OpenVINO 对齐，以及固定 Paddle Predictor 的独立 CPU 输出。候选继续保持 `Preview`，因为 `license-and-redistribution` 仍为 open：尚无可归属的批准覆盖模型归档及其派生 ONNX 的再分发。详见 [ADR 0037](../adr/0037-ppocrv5-first-algorithm-admission.md)。

## Stage 27 document intelligence / 阶段 27 文档智能

Official Donut CORD-v2 revision `8003d433...` is the executable single-page OCR-free structured-extraction representative. Its exact Processor/Tokenizer/Schema and three-role Encoder/Prefill/KV Decode bundle runs on ORT CPU and OpenVINO FP32 IR CPU through the real OpenCV source-page path, matching the official Predictor's 53 completion tokens, EOS, fields, and JSON. All three manifests are `redistributionAllowed:false`, outside the current 40-entry official catalog, with uploaded/downloadable both false. See [the guide](visual-document-understanding.md), [acquisition procedure](model-acquisition-document-understanding.md), [API changes](../history/api-changes-stage27.md), and `eng/models/document-understanding/document-understanding-family-support.json`. / LayoutLMv3 与 Pix2Struct 保持精确 blocker；三份 Manifest 禁止再分发且不进入当前 40 条 Catalog。

## ModelFactory asset policy / ModelFactory 资产策略

- Prefer reproducibly exported portable ONNX and OpenVINO IR artifacts. TensorRT `.engine`/`.plan` remains device, CUDA, TensorRT and builder-version bound and is never a universal catalog asset. / 优先收录可复现导出的可移植 ONNX 与 OpenVINO IR；TensorRT `.engine`/`.plan` 与设备、CUDA、TensorRT 和 builder 版本绑定，绝不作为通用目录资产。
- Each accepted artifact records the upstream repository/release/commit, original checkpoint, exporter version and arguments, opset, tensor names/shapes, precision, size, SHA256, license, test image license, golden result and verified backends. / 每个准入工件必须记录上游仓库/Release/commit、原始 checkpoint、导出器版本与参数、opset、张量名称/形状、精度、大小、SHA256、许可证、测试图片许可证、黄金结果和已验证后端。
- The Ultralytics repository currently declares AGPL-3.0. Weight and dataset terms can differ. A model is not mirrored into a DeploySharp GitHub Release until its exact asset terms permit redistribution and the required notices/source obligations are prepared. / Ultralytics 仓库当前声明 AGPL-3.0；权重和数据集条款可能不同。只有精确资产条款允许再分发，且所需声明/源码义务已准备完成后，模型才能镜像到 DeploySharp GitHub Release。
- `E:\Model` is an authorized read-only validation source. Its 2026-08-06 inventory contains 176 ONNX files plus OpenVINO IR, checkpoints and device-bound engines. Local presence is not proof of provenance, license or catalog approval. / `E:\Model` 是获准使用的只读验证源；2026-08-06 清单包含 176 个 ONNX 及 OpenVINO IR、checkpoint 和设备绑定 engine。本机存在不代表来源、许可证或目录准入已通过。

The embedded official catalog contains the reviewed Qwen, vision previews, and the six PP-OCRv5 mobile/server detection, recognition, and orientation-classification previews. Every other local or external model remains excluded unless its own immutable release, manifest, and admission evidence are present. / 内置官方目录已包含经审核的 Qwen、视觉 Preview，以及六个 PP-OCRv5 mobile/server 检测、识别和方向分类 Preview；其他本地或外部模型在具备各自不可变 Release、清单与准入证据前继续排除。
