# Acquire and convert DETR and RT-DETR models / 获取与转换 DETR 与 RT-DETR 模型

Choose a manifest under `eng/models/detr/manifests` before obtaining a file. Paddle decoded `boxes/boxes_num`, Paddle raw query logits/boxes, RT-DETRv2 deploy triplets, RF-DETR queries/masks, DEIMv2 rows, and PP-YOLOE outputs are different contracts. Preserve official named ports and auxiliary tensors such as `im_shape`, `scale_factor`, and `orig_target_sizes`; their values come from the single typed preprocessing contract. / 获取文件前先选择 DETR Manifest。Paddle 已解码、raw query、RT-DETRv2、RF-DETR、DEIMv2 与 PP-YOLOE 合同不同；辅助张量必须由单一 typed 前处理合同生成。

Create `E:\DeploySharp-Models\<model-name>\original` and `converted-<format>` directories, pin the official repository commit and exporter, verify the checkpoint hash, and save the full export command and environment lock. For PaddleDetection use its official `tools/export_model.py` output first, then a pinned Paddle-to-ONNX conversion only when the graph and auxiliary inputs remain traceable. Keep the Stage 18 Tile failure file unchanged as evidence; never overwrite a user model while repairing an export. / 使用官方导出链并保存完整命令与依赖锁。阶段 18 Tile 失败工件必须保留，不覆盖用户模型。

After export, enumerate graph metadata and run the contract-specific ORT/OpenVINO gate with an authorized image. Compare class, score, box order, threshold decisions, source coordinates, and whether NMS is graph-owned or DeploySharp-owned. See `visual-portable-detectors.md`, Stage 18/21 API changes, and each manifest for exact sizes, SHA, blockers, and backend evidence. / 导出后按合同执行双后端并比较完整字段；精确值以指南、API Changes 和 Manifest 为准。
