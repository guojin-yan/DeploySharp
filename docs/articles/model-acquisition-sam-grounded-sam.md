# Acquire SAM and Grounded-SAM models / 获取 SAM 与 Grounded-SAM 模型

Store each official checkpoint and each converted component under `E:\DeploySharp-Models\<model-name>`, with encoder/decoder/external-data or IR sidecars in a named conversion directory. Select an exact `eng/models/sam/manifests` or `eng/models/open-vocabulary/manifests` record first. SAM v1, SAM 2, and SAM 3 image encoders, prompt decoders, memory graphs, and video trackers are not interchangeable. / 每个官方 checkpoint 与转换组件按模型名集中存储，并先选择精确 Manifest。SAM v1/2/3 的 Encoder、Prompt Decoder、Memory 与 Video Tracker 不可互换。

For SAM v1, pin Meta's official repository/checkpoint, export the image encoder and official prompt/mask decoder without replacing prompt logic, and record point/box/mask-feedback coordinates, original size, low-resolution logits, multimask quality, and threshold. Hash every ONNX external-data file or OpenVINO XML/BIN sidecar. Compare the official predictor and DeploySharp masks pixel-by-pixel/IoU on an authorized image. / SAM v1 必须导出官方双子图并记录 Prompt、低分辨率 Logit、质量和阈值；所有 Sidecar 均需哈希并做官方像素/IoU 对照。

Grounded-SAM is a composition, not a single checkpoint: separately acquire an exact vocabulary-bound open-vocabulary detector and a complete SAM bundle, then bind both identities in `GroundedSamImageSession`. Do not manually recover coordinates between them. SAM 2/3 prompt-memory/video paths remain blockers unless a complete official native export can be audited. See `visual-sam-family.md` and `visual-open-vocabulary.md`. / Grounded-SAM 是两个完整 Bundle 的组合，不是单 checkpoint；必须分别审核并绑定 Identity。SAM 2/3 Memory/Video 在完整官方 Native Export 出现前保持 blocker。
