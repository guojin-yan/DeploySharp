# DeploySharp V2 文档

DeploySharp V2 是面向 .NET 的模型部署工具。它通过显式后端、模型制品和运行时边界，提供视觉、语言与多模态推理能力。

当前 `2.0.0-alpha.1` 是 Windows x64 工程预览版。V2 为全新 API，不提供与 V1 的源码、二进制、配置或行为兼容。
