# SLANeXt dynamic Batch decoding evidence (2026-10-05)

This record verifies the true dynamic input batch contract for the wired SLANeXt table-structure export. It uses two identical rows from the same table image, runs the official ONNX graph with ONNX Runtime CPU, and runs the separately alpha-renamed OpenVINO-compatible graph with OpenVINO CPU. The test exercises input preparation, backend binding, the two-output table decoder, per-row result isolation and deterministic markup comparison.

This is a single-host execution contract. It is not a table-structure accuracy score, a throughput benchmark, or evidence that the original Release graph imports in OpenVINO. The original `slanext-wired.onnx` remains blocked by the current OpenVINO `Loop` importer; the OpenVINO row below uses the derived compatibility artifact and its independent SHA-256.

## Reproduction boundary

Run the test from the repository root after placing the two local artifacts at the paths above:

```powershell
$env:DEPLOYSHARP_PADDLE_DOCUMENT_DYNAMIC_BATCH_RUN_EXTERNAL = '1'
$env:DEPLOYSHARP_PADDLE_DOCUMENT_SLANEXT_DYNAMIC_BATCH_REPORT_PATH = (Join-Path (Get-Location) 'eng/models/paddle-document/verification/paddle-document-slanext-dynamic-batch-ort-openvino.json')
dotnet test tests/DeploySharp.Visual.OpenCV.Tests/DeploySharp.Visual.OpenCV.Tests.csproj `
  -f net10.0 --configuration Debug --no-restore --verbosity minimal `
  --filter FullyQualifiedName~OfficialDynamicBatchSlaNextRunsOnOrtAndOpenVino
Remove-Item Env:DEPLOYSHARP_PADDLE_DOCUMENT_DYNAMIC_BATCH_RUN_EXTERNAL
Remove-Item Env:DEPLOYSHARP_PADDLE_DOCUMENT_SLANEXT_DYNAMIC_BATCH_REPORT_PATH
```

The compatibility file is generated by `eng/models/paddle-document/scripts/Build-PaddleDocumentOpenVinoCompatibility.ps1` and must remain a separate artifact. Do not change the original Release file or mark all SLANeXt/OpenVINO combinations as supported from this one derived graph. TensorRT, OpenCV DNN, wireless SLANeXt and task-level table accuracy remain separate matrix items.
