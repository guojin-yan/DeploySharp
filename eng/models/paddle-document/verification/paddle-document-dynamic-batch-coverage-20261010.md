# PP-Structure dynamic-batch coverage summary (2026-10-10)

This is a coverage index for PP-Structure assets whose exported graph exposes a dynamic first input axis and whose DeploySharp profile/decoder has a meaningful batch contract. It is not a claim that every backend supports dynamic batch, nor a throughput or accuracy benchmark. Every status below is for the exact artifact and runtime named in the linked evidence.

## Interpretation

The summary closes the **inventory and representative execution-coverage** item for dynamic PP-Structure Batch on this Windows host. The exact PP-LCNet table-classification, document-orientation, PP-OCRv4 seal mobile/server and UVDoc TensorRT combinations now have checked execution/parity rows; the remaining TensorRT dynamic-batch families remain `△`. OpenCV importer limitations, formula quality, long-text quality, model-level accuracy, cross-device performance, and long-running stability gates remain open. Static exports remain valid through independent session/page concurrency and are not silently relabelled as model Batch support.

`*` TensorRT is shown as `✓*` for UVDoc and the PP-OCRv4 seal row because the exact TRT11 artifacts have DeploySharp batch=2 results; the grouped PP-Structure rows remain per-artifact claims and must not be read as blanket TensorRT Batch support.
