# PaddleOCR-VL bounded image-region fallback

Date: 2026-10-26. Scope: fixed PaddleOCR-VL-1.6 public Bundle, PP-DocLayout-L detector, two preselected FUNSD test pages. The opt-in fallback changes only layout-to-task routing; default `image` handling remains skip. Source scans, labels, generated text and full page exports remain outside Git.

The [offline word-coverage audit](paddleocr-vl-funsd-layout-routing-coverage-20261026.md) found that 74 of 75 annotated word centers on page `86220490` fell only in a skipped `image` box. An isolated manual override ran `TextRecognition` for that box only on Ubuntu 22.04.5 / ONNX Runtime CPU. The process exited 0 with EOS and 151 generated tokens. Its wall time was 43.40 s and peak RSS was approximately 7,372,500 KiB; the page export's pipeline `elapsedMs` was 25,982.7848 ms. These are different one-run measurements, **not P50/P95**. Raw export: `E:\DeploySharpEvidence\paddleocr-vl-release-detected-pages-20261026\page-3-image-fallback-result.json`, SHA-256 `868f94154e8741842193f7317a04e67338aa64224c68de439d059a533797664f`. The isolated override explicitly skipped the three smaller normal boxes; it is not a full-page automatic-fallback run.

For that image box, 74 annotated words produce 68 terms after NFKC, lowercasing and alphanumeric tokenization. The isolated output has the same 68-term multiset with no extra terms. Six punctuation-only annotations are excluded. This is a **bag-of-terms check**, not reading-order accuracy, CER/WER, representative OCR quality or proof that enabling fallback improves every page.

The opt-in router selects candidate `image` boxes only when their uncovered area fraction is at least 0.25, then keeps at most one per page by largest uncovered area (stable source-index tie-break). Coverage is the union of intersections with normally routed regions, so overlapping normal boxes are not double-counted. Real detector geometry is covered by a no-model contract: page 3's large image remains eligible, whereas page `87147607` has an `image` box exactly coincident with its already routed `table` box and stays skipped. Synthetic contracts also cover union coverage, budget, explicit category-task priority, default-off behavior and warning/index preservation. These checks do not rerun the large Bundle.

Only `image` is eligible, not other picture labels or undetected pixels. A non-null explicit image task still runs all matching boxes regardless of the fallback budget. An explicit null image mapping with fallback enabled delegates to this bounded geometric rule. The policy cannot diagnose image content, remove duplicate text from other routed boxes, or compensate for absent detector boxes. Keep it opt-in and assess the application's own pages before raising the region budget.

Selection is based on planned category routes before generation. A normally routed region that later fails does not trigger a second fallback selection.

Focused verification: `PaddleOcrVlLayoutStageTests` 30/30 passed on .NET 10; the .NET 8 document sample built with 0 warnings and 0 errors. No second large-model inference was run for this code change. The real-box regression checks routing geometry, while the isolated manual override above supplies the separate model-generation evidence.
