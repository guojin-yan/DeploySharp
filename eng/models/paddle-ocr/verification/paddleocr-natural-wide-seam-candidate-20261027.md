# Natural wide-line seam candidate: independent test follow-up (2026-10-27)

The original [independent test-split report](paddleocr-hiertext-test-natural-wide-a2-ort-20261026.md) remains an unchanged baseline. This follow-up changes only the shared CTC window merger: a bounded fuzzy match can leave unmatched right-hand suffix tokens intact, and a matching first token just outside the geometric boundary can anchor the overlap. Existing full-prefix and unique-subsequence matches retain priority. The shorter-prefix search is limited by the configured edit budget; a right-only leading token cannot be swallowed merely to obtain a shorter match. Geometric fallback remains marked `SeamUncertain`, even with zero token edits. Clamp, crop geometry, model inputs and public defaults are unchanged.

The pinned HierText `test` selection is the same 17 natural lines in 11 images, separate from the `validation` seam-development split. Main quality includes 12 officially legible lines with source height at least 2px (1,945 Unicode scalars and 315 whitespace words); five officially illegible lines remain diagnostic.
