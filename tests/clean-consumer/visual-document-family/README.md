# DeploySharp document-family clean consumer

This package-only executable installs Core, Visual, Visual.OpenCV, one ONNX Runtime backend adapter, and application-selected Windows x64 OpenCV and ORT native runtimes. It has no project reference and no model, checkpoint, tokenizer, processor, schema, OCR data, document, Golden, Python, OpenVINO, TensorRT, or hidden native runtime inside a DeploySharp package. / 此纯包可执行程序安装 Core、Visual、Visual.OpenCV、一个 ONNX Runtime Backend Adapter，以及由应用显式选择的 Windows x64 OpenCV 与 ORT Native Runtime；DeploySharp 包内不含项目引用、模型、Checkpoint、Tokenizer、Processor、Schema、OCR 数据、文档、Golden、Python、OpenVINO、TensorRT 或隐藏 Native Runtime。

Set `DEPLOYSHARP_DOCUMENT_MODEL_ROOT` to the external `donut-base-finetuned-cord-v2` warehouse directory. Missing external files print `DEPLOYSHARP_VISUAL_DOCUMENT_FAMILY_CONSUMER_SKIP`. A real OpenCV prepare, Encoder, Prefill, KV Decode, strict CORD parse, and Clear lifecycle prints `DEPLOYSHARP_VISUAL_DOCUMENT_FAMILY_CONSUMER_OK`. LayoutLMv3 task heads, Pix2Struct dynamic-patch export, multi-page execution, OCR routing, sampling, Beam, arbitrary JSON repair, and TensorRT are not claimed. / 将环境变量指向外部 Donut warehouse 目录；缺文件稳定输出 Skip。真实 OpenCV Prepare、Encoder、Prefill、KV Decode、严格 CORD 解析与 Clear 生命周期成功后输出指定成功标记；不宣称尚未验证的能力。
