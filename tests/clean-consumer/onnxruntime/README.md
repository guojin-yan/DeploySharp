# ONNX Runtime package-only consumer / ONNX Runtime 纯包消费者

This executable uses only packed DeploySharp packages plus the application-selected official `Microsoft.ML.OnnxRuntime` CPU package. It performs one named Core inference and one Visual classification. / 此可执行程序仅使用已打包的 DeploySharp 包和应用选择的官方 `Microsoft.ML.OnnxRuntime` CPU 包，并执行一次 Core 命名推理与一次 Visual 分类。
