# Visual instance segmentation clean consumer

This package-only executable installs `JYPPX.DeploySharp.Visual`, the ONNX Runtime backend, and the user-selected CPU runtime. It executes the repository-owned Direct instance segmentation contract fixture and prints `DEPLOYSHARP_VISUAL_INSTANCE_SEGMENTATION_CONSUMER_OK` after validating independent masks, deterministic ordering, SHA-256, and overlap ownership.

# Visual 实例分割干净消费者

此仅包引用的可执行程序安装 `JYPPX.DeploySharp.Visual`、ONNX Runtime 后端及用户选择的 CPU runtime。它执行仓库自有的 Direct 实例分割合约夹具，并在验证独立掩码、确定性排序、SHA-256 和重叠所有权后输出 `DEPLOYSHARP_VISUAL_INSTANCE_SEGMENTATION_CONSUMER_OK`。
