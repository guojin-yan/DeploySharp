# ModelFactory clean consumer / ModelFactory 独立消费验证

This project references only the packed `JYPPX.DeploySharp.ModelFactory` package. It creates a valid in-memory Release fixture, downloads and verifies a ModelPack through a custom HTTP handler, then reopens the same cache in offline mode. / 本项目只引用已打包的 `JYPPX.DeploySharp.ModelFactory`。它创建有效的内存 Release 夹具，通过自定义 HTTP handler 下载并验证 ModelPack，然后以离线模式重新打开同一缓存。

No real model, GitHub Release, native runtime, or project reference is used. / 不使用真实模型、GitHub Release、原生运行时或项目引用。
