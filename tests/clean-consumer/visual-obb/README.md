# Visual OBB clean consumer / Visual OBB 独立消费验证

This package-only application installs DeploySharp Visual, the ONNX Runtime adapter, and the application-selected ONNX Runtime CPU native package. It executes the reproducible `direct-obb.onnx` contract fixture and prints `DEPLOYSHARP_VISUAL_OBB_CONSUMER_OK`. / 此 package-only 应用安装 DeploySharp Visual、ONNX Runtime 适配器以及由应用选择的 ONNX Runtime CPU 原生包，执行可复现的 `direct-obb.onnx` 合同夹具并输出 `DEPLOYSHARP_VISUAL_OBB_CONSUMER_OK`。

The fixture is not an official OBB algorithm or model asset. / 该夹具不是官方 OBB 算法或模型资产。
