# PaddleOCR-VL test fixtures

These files are pinned reference vectors consumed by tokenizer, position-planning, table-parser, spotting-parser, and opt-in latency tests. They are deliberately stored with the tests instead of in a dated validation-report directory.

The fixtures preserve their upstream revisions and SHA-256 provenance. They validate deterministic contracts only; they are not a model-quality or all-backend support claim.
