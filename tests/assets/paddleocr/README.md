# PaddleOCR test fixtures

These JSON files are deterministic inputs consumed by opt-in long-text contract tests. They are fixtures, not benchmark reports or claims about general model accuracy.

- `natural-wide-selection.json` fixes the annotated HierText line selection.
- `natural-wide-baseline.json` fixes the corresponding baseline output used by trace replay.

The source report names and full development evidence are retained outside the public repository in the engineering archive.
