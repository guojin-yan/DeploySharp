# PaddleOCR-VL ONNX CPU example

This example runs the experimental PaddleOCR-VL-1.6 four-graph bundle through the production C# `PaddleOcrVlOnnxSession` and ONNX Runtime CPU backend. It prints the raw generated text, token count, termination reason and generation time.

The sample intentionally accepts a prepared little-endian `float32` patch file. The file must be generated by the pinned official PaddleOCR-VL Processor and contain the exact `[grid_h, grid_w, 3, 14, 14]` RGB-normalized tensor for one image. This keeps the sample honest: automatic image decoding, resize, spotting's special preprocessing and patch construction are not part of the current public path.

The four graph files must be one matching export set: `vision.onnx`, `embedding.onnx`, `decoder.onnx` and `head.onnx`. The tokenizer directory must contain the pinned official `tokenizer.model`, `tokenizer.json`, `tokenizer_config.json` and `chat_template.jinja`.

```powershell
dotnet run --project samples/02-visual/paddleocr-vl-onnx/PaddleOcrVlOnnx.csproj -c Release -- `
  E:\Model\PaddleOCR-VL\1.6\c5630abae1d940eafe0697512a0325494b02ab42 `
  E:\Model\PaddleOCR-VL\exports\dynamic-fp32-20261023 `
  E:\Model\PaddleOCR-VL\inputs\ocr-demo-1-pixel_values.bin `
  672 448 TextRecognition
```

The checked-in [Linux ORT evidence](../../../eng/models/paddle-ocr/verification/paddleocr-vl-managed-csharp-ort-linux-20261024.json) covers six fixed real images and all six supported task prompts. It is a correctness record, not a performance ranking. OpenVINO, TensorRT, OpenCV DNN, GPU execution, automatic Processor support and page/multi-page PP-Structure orchestration remain unverified.
