# Multimodal workflow / 多模态工作流

MultimodalContractInspection runs ordered media input, an in-memory inference adapter, streaming output, cancellation, and lifecycle disposal together. It is a backend-neutral orchestration case, not a one-method API check.

```powershell
dotnet run --project samples/04-multimodal/MultimodalContractInspection.csproj -c Release
```
