# Per-model cases / 模型独立案例

Every current official catalog entry has its own folder below this directory. Each README defines one complete case boundary: catalog selection, artifact/package verification, input preparation, backend/session choice, task decoding, and output ownership.

The three published vision model cases have a real executable under ../release-inference. The remaining cases start with the catalog workflow and identify the exact runtime/input prerequisites for their task; they are intentionally not reported as inference-passed until those prerequisites are available.

Run any case command from the repository root.

Each case README also contains a verification record generated by eng/model-catalog/Test-PublishedModelCases.ps1. The record distinguishes release/catalog/ModelPack integrity from the runtime evidence declared by the published ModelPack. Use -DownloadAssets when a local full-payload SHA256 check is required.
